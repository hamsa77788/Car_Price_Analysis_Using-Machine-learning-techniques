## Overview

This project applies machine learning techniques to analyze and predict car prices using a real-world automotive dataset. The project addresses both regression and classification tasks using the same preprocessing pipeline.

## Objectives

The project focuses on two machine learning problems:

1. **Regression**

   * Predict the exact selling price of a car.

2. **Classification**

   * Categorize cars into price groups:

     * Cheap
     * Moderate
     * Expensive

## Dataset

The dataset contains information about vehicles, including various features that influence car prices such as model specifications, manufacturing details, and market-related attributes.

## Project Workflow

### Exploratory Data Analysis

### Regression Modeling
